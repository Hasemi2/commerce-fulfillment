# Product Domain

## Responsibility

`Product`는 상품명, 가격, 판매 상태와 같은 상품 기준 정보를 관리한다. 생성 및 상태 변경 시 도메인 내부에서 이름과 가격의 유효성을 검증한다.

## Current Scope

- 유효한 상품 생성
- 상품명 및 가격 변경을 위한 도메인 메서드
- `ACTIVE`, `DISCONTINUED` 상태 관리
- 활성화 및 판매 중단을 위한 도메인 메서드
- 상품 등록 및 조회 API

## Known Gap

주문 생성 시 `DISCONTINUED` 상품은 거부해야 한다. 상태와 상태 변경 도메인 메서드는 존재하지만, 현재 `OrderService`는 조회한 상품의 상태를 검사하지 않는다.

이는 현재 구현에서 빠진 비즈니스 검증이며 판매 중단 상품도 주문될 수 있다. 문서로 허용한 정책이 아니다.

## Out of Scope

- 상품 수정 API
- 상품 판매 상태 변경 API
- 카테고리, 옵션, 프로모션 등의 상품 카탈로그 기능

## Future Considerations

현재 토이 프로젝트에는 상품 관리 기능을 확장할 계획이 없다. 향후 요구사항이 추가될 경우에만 상품 수정 및 판매 상태 관리 API를 검토한다.
